# 独立评估与收敛

评估者需要原始图片、当前图的绝对路径、当前阶段、用户明确的尺寸/风格要求。不要把上一位评估者的结论、你怀疑的错误或希望通过的项目作为首次盲评提示。后续定向复核可以给出具体已改项，报告注明它是局部复核。

## 灰模首次评估提示

“作为独立结构评估者，只读查看以下原图和当前灰模。指出最影响相似度的可见差异，最多优先列三项。每项给出图中位置、观察证据、可能归因（相机/几何/信息不足）和下一次可验证的改法。将明确可见差异与单图无法确定的部分分开。不得修改文件，也不要给出没有测量依据的整体相似度百分比。返回是否有应先处理的明显问题。”

## 材质首次评估提示

“只读比较参考图和当前渲染，检查软硬材质、颜色、粗糙度、透明层次和受光。指出主要差异及证据，区分材质设置与光照/色彩管理的可能影响；不确定时提出一次最有用的对照渲染。不要假定灰模已通过就代表材料正确，也不要把渲染误差一律归为几何。”

## 记录

`reviews/review.json` 的基本形态：

```json
{
  "status": "pending",
  "observations": [],
  "accepted_changes": [],
  "remaining_differences": [],
  "blockers": [],
  "evidence": [],
  "reviewers": []
}
```

完成实际评估后可将 status 设为 `reviewed`。它仅表示做过评估，不表示全项通过。accepted_changes 写具体已确认修正；blockers 写当前仍应优先修正的明显问题；remaining_differences 写可见残差和推定边界，并区分二者。evidence 使用项目内相对路径。reviewers 记录角色与是否独立，不捏造人员或通过结论。

有 blocker 时继续修订，或按用户要求用草稿模式交付。不要为了让打包脚本成功而清空真实问题。未知背面不是要求用户不断确认的理由；记录合理假设并继续能做的部分。

比例可使用包围框、圆面椭圆比、轮廓地标等辅助。截图中的估计需注明误差；一个投影指标通过只证明该指标，不证明整体形状正确。跨轮保持相机和灯光条件可比较，若发生变化记录原因。

统一灰材质会使透明外罩变不透明，内部支撑可能被遮住。此时灰模只适合外轮廓检查；补看独立零件、爆炸图或合适的剖切视图，不能把“灰模看不到内部结构”误判为结构缺失。
